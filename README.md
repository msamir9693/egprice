# مقارنة الأسعار في مصر

موقع ثابت بيقارن أسعار **الشاشات** بين المحلات المصرية. بيعرض أرخص سعر الأول، وأكبر فروق الأسعار النهارده، والعروض المميزة.

## المحلات (آخر تجربة على صفحات حقيقية: 2026-11-10)

| المحل | الحالة | بنقرأ منين |
|---|---|---|
| Amazon.eg | شغال (أحياناً بيرجّع صفحة تحقق من البوتات) | بحث لكل عيلة موديل، والكود بيبان في رابط المنتج |
| 2B | شغال | بحث بالبراند (`samsung tv`)، والكود في آخر العنوان |
| Raya | شغال | صفحات البراند (`/en/tv-samsung`)، لأن البحث بيتحمّل بجافاسكريبت |
| B.Tech | شغال | صفحة كاتيجوري الشاشات (JSON جوه الصفحة)، أول 20 منتج بس |
| Jumia | متوقف | Cloudflare بيرجّع تحدي 403 على كل طلب |
| Noon | متوقف | الاتصال بيتقفل أو بيعمل timeout |

مش بنحاول نتخطى أي كابتشا أو تحدي. لو محل رجّع حجب، بنسجّل ده ونوقف الطلبات عليه لحد التحديث الجاي.

## إزاي بيشتغل

1. `products.json`: لكل شاشة **كود موديل** (مثلاً `55U8000H`) وحد أدنى للسعر.
2. `scrapers/`: ملف لكل محل. كل ملف فيه `listing_urls()` (الصفحات اللي هنقراها) و`parse()` (بيطلّع العنوان والسعر والرابط والـ SKU).
3. `matching.py`: بيطابق العرض مع المنتج بكود الموديل بعد ما يوحّد شكله. فـ `UA55U8000HUXEG` و`ua55u8000h` والـ SKU بتاع B.Tech `1TSATVSM55U8000HL007` كلهم بيتطابقوا مع `55U8000H`، لكن `UA50U8000H` و`UA55DU8000` لأ. وكمان بيرفض الإكسسوارات، والأسعار اللي تحت الحد الأدنى، والسعر اللي أقل من 60% من متوسط باقي المحلات.
4. `engine.py`: بيجيب الصفحات بتأخير 3 لـ 6 ثواني بين الطلبات على نفس الموقع، ويسجّل كل طلب في `data/run.log`، وفي الآخر بيطلّع ملخص لكل محل. بعدها بيحفظ تاريخ الأسعار ويحسب الفروق والعروض.
5. `build_site.py`: بيبني `docs/index.html`.

## التشغيل

```bash
pip install -r requirements.txt
```

```bash
powershell -ExecutionPolicy Bypass -File run_local.ps1
```

السكريبت بيحدّث الأسعار ويبني الصفحة. ولو الفولدر متربط بـ GitHub، بيرفع التحديث كمان.

الاختبارات بتشتغل من غير إنترنت:

```bash
python -m unittest discover -s tests -v
```

## إضافة شاشة

زوّد سطر في `products.json` فيه `brand` و`family` (اللي بيتعمل بيه البحث في أمازون) و`model` و`min_price`. ولو محل بيكتب الكود ناقص (2B مثلاً بيكتب `UA43F6000` من غير الـ F الأخيرة)، حط الشكل ده في `aliases`.

## حدود لازم تعرفها

- **B.Tech** بيعرض أول 20 شاشة بس في الصفحة (الأكتر مبيعاً). أي موديل برّه الـ 20 دول مش هيظهر في B.Tech.
- **سعر B.Tech** هو السعر **قبل** كوبون السلة، لأن الكوبون بيتطبق عند الدفع.
- **أمازون** ممكن يرجّع صفحة تحقق (Akamai). لما ده يحصل، بنتخطى أمازون في التحديث ده.
- الـ selectors ممكن تتغير لما المواقع تعدّل تصميمها. لو محل بقى فاضي، هتلاقي في `data/run.log` سطر بيقول "0 products parsed".
